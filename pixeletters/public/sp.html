Read the Colors

After each guess, the pixels light up to show how close you are:

✓
Blue — Correct letter, correct position (fully revealed)
●
Green — Revealed pixels that match the target letter
✗
Red — Revealed pixels that don't match the target
?
Gray — Pixels not yet revealed
🔤 The keyboard also shows pixel previews for each letter you've guessed, helping you track what you know.
