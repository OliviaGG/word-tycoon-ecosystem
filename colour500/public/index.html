How to play

Crack the secret color code. Everyone plays the same code — the first to get it takes the pot.

Making a guess

Tap colors from the palette at the bottom to fill the row, then press enter. ⌫ takes the last one back. On a keyboard, the color's first letter works too.

Reading the triangle

  • right color, right slot
  • right color, wrong slot
  • not in the code at all

It never tells you which slot — that's the whole game. Colors can repeat in the secret.
